# NEXUS — DOMAIN SUPPORT MATRIX

Trạng thái: Phase 0 audit. Bảng này phản ánh cái đang chạy thực tế trong working tree, không phải cái sẽ xây. Cột "Bằng chứng" là file:line hoặc lệnh đã chạy. Không có mock tool nào được tính là hỗ trợ.

Chú giải:

- IMPLEMENTED + TESTED: có code, có unit/E2E/probe chạy xong.
- PARTIAL: có nền tảng dùng được, thiếu adapter chuyên sâu hoặc chưa integration test.
- REQUIRES INSTALL: cần cài tool ngoài (xem DEPENDENCY_MATRIX.md).
- REQUIRES LICENSE: cần license/SDK thương mại.
- UNSUPPORTED: không áp dụng cho môi trường này.
- PLANNED: chưa có code; nằm trong IMPLEMENTATION_PLAN.md.

## D. Quy tắc ghi nhận trạng thái

1. Detect executable ≠ tested. Phải chạy project mẫu trong temp dir, capture exit code/log thì mới chuyển IMPLEMENTED+TESTED.
2. Tool thiếu → ghi REQUIRES INSTALL kèm nguồn cài trong DEPENDENCY_MATRIX.md; không hiển thị UI success.
3. OS không hỗ trợ → UNSUPPORTED, kèm lý do (ví dụ iOS/Xcode trên Linux).
4. License thương mại → REQUIRES LICENSE; không giả đã có license.
5. Sau mỗi integration test, cập nhật bảng này trong cùng PR với log/exit code làm bằng chứng.
